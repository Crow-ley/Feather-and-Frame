Overhang Regions

Tool

Move: drag to place, scroll to resize. Restore paints the image back. Erase removes it. Lasso and Fuzzy select areas.

Size of the Restore and Erase brushes.

Selection

New replaces the selection. Add and Subtract change it. Shift and Alt do the same.

Higher grabs a wider range of similar colors.

Drag around an area, or click points and click the first one to close.

Click a color to select the connected area around it.

Restore and Erase respect the selection.

Reset Image re-sizes and centers the image. Remove Edits clears all brush and selection edits.

Ctrl+scroll zooms, Space+drag pans, Ctrl+Z undoes, [ ] size the brush.

Makes the image bigger or smaller inside the ring.

Background

Removes the plain background touching the edges of the image.

Raise it for uneven or shaded backgrounds. Lower it if parts of the character disappear.

Create Dynamic Ring

Shown in Foundry's Dynamic Token Rings setting. Uploading again under the same name replaces that ring.

Remove Dynamic Rings

Rings are shared by every world on this server. Removing one takes it off Foundry's Dynamic Token Rings list in every world after their next reload; a world using it goes back to Foundry's Steel ring. Its .json and .webp files stay in the ring spritesheet folder, so delete them there if you don't need them. Uploading under the same name adds it back.
